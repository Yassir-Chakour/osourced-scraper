# Osourced Scraper — Agentic Upgrade Plan

## 1. What We're Building

A LangGraph-powered bot that:
1. Scrapes osourced.is for new jobs
2. Generates personalized German cold emails (with a better 2-step prompt)
3. **Pauses and sends you a Telegram message** with the job + pitch for review
4. **Understands your natural language reply** (not just /approve — you can say "make it shorter" or "skip this one")
5. If you say modify → regenerates and asks again
6. If you approve → submits the application
7. Sends you a final summary report
8. Handles website changes gracefully with screenshots + alerts

## 3. LangGraph Flow

```
START
  │
  ▼
[health_check]          ← Verifies key selectors exist on the page
  │  FAIL → alert_telegram → END
  │  OK
  ▼
[login]                 ← Playwright login
  │  FAIL → alert_telegram → END
  │  OK
  ▼
[scrape_jobs]           ← Collect job listings (title, link)
  │  0 jobs → alert_telegram("no jobs found") → END
  │
  ▼
[filter_applied]        ← Remove URLs already in applied_jobs.json
  │  All filtered → send_report → END
  │
  ▼
[for each unapplied job] ← loop via LangGraph conditional edges
  │
  ├─► [extract_details]      ← Playwright: get description, salary, company
  │
  ├─► [extract_pain_points]  ← LLM Step 1: find manual tasks in job description
  │
  ├─► [write_pitch]          ← LLM Step 2: write email using extracted pain points
  │
  ├─► [validate_pitch]       ← Check word count, language, no [placeholders]
  │       FAIL → regenerate once → if still fails → alert you
  │
  ├─► [notify_telegram]      ← Send job card + pitch to you
  │
  ├─► [INTERRUPT]            ← Graph pauses. Waits for your Telegram reply.
  │
  ├─► [understand_reply]     ← LLM classifies your reply:
  │       APPROVE / REJECT / MODIFY(instructions)
  │
  ├─► if MODIFY → back to [write_pitch] with your feedback → [notify_telegram]
  ├─► if REJECT → mark job as skipped, next job
  └─► if APPROVE → [apply] → [mark_applied in applied_jobs.json] → next job
  │
  ▼
[reporter]              ← Build summary: X found, Y applied, Z skipped, errors
  │
  ▼
[send_report_telegram]  ← Final Telegram message with summary
  │
  END
```

## 4. State Schema (graph/state.py)

```python
from typing import TypedDict, List, Optional, Literal

class Job(TypedDict):
    title: str
    link: str
    salary_range: str
    description: str
    company_name: str
    pain_points: List[str]           # extracted by LLM step 1
    pitch: str                       # generated by LLM step 2
    user_feedback: str               # your last Telegram message
    modification_rounds: int         # how many times you asked to modify
    status: Literal["pending", "approved", "rejected", "applied", "error"]
    error_message: Optional[str]

class GraphState(TypedDict):
    jobs: List[Job]
    current_job_index: int
    run_id: str                      # timestamp of this run
    errors: List[str]                # global errors
    telegram_chat_id: str
```

- **Never wiped** — permanent record
- Checked before processing any job — if URL already here, skip automatically

> **Why not wipe this?** The site may re-list old jobs. We never double-apply.
> Optional: archive entries older than 60 days to keep file lean.

## 6. Telegram Bot Design

### Setup
- Library: `python-telegram-bot` (async, polling mode)
- **Polling** not webhook — simpler for Docker, no public URL needed
- Bot listens in a background thread while LangGraph runs

### Message Format (what you receive per job)

```
🆕 New Job Found

📌 Assistenz der Geschäftsführung
💰 3.000 – 4.000 €/Monat
🏢 MusterGmbH
🔗 https://osourced.is/jobs/1234

🎯 Pain Points erkannt:
• Kalender- und Reisemanagement
• Manuelle Belegerfassung in Excel

✉️ Generierter Pitch:
─────────────────────
Sehr geehrte Damen und Herren,

ich habe gesehen, dass Sie Unterstützung für Assistenz suchen.
Kalender koordinieren, Belege erfassen — das kostet täglich Stunden.
Genau diese Abläufe automatisieren wir.

Haben Sie die nächsten 5 Minuten für einen kurzen Austausch?

Beste Grüße,
Yassir Chakour
─────────────────────

Antwort: gut so / überspringen / kürzer machen / ...
```

### Reply Intent Classification

The LLM reads your free-text reply and classifies it into:

```python
class ReplyIntent(TypedDict):
    action: Literal["approve", "reject", "modify"]
    modification_instructions: Optional[str]
```

| Your message | Action | Instructions |
|---|---|---|
| "sieht gut aus" / "perfekt" / "schicken" | `approve` | — |
| "überspringen" / "nope" / "skip" | `reject` | — |
| "kürzer machen" | `modify` | "make it shorter" |
| "füge was über Rechnungen hinzu" | `modify` | "add something about invoices" |
| "weniger formal" | `modify` | "less formal tone" |

**Max modification rounds:** 3 — after 3, sends you a final message:
> "⚠️ 3 Runden erreicht. Soll ich trotzdem abschicken oder überspringen?"

### Alert Messages (for errors, not jobs)

```
⚠️ Bot Alert

Node: health_check
Error: Selector 'h3 a' returned 0 results — website may have changed.
Screenshot: [attached image]
Run ID: 2026-07-08T09:00:00

Bot stopped. Manual check needed.
```

## 7. Prompt — 2-Step Approach

### Step 1: Pain Point Extractor

```
Analysiere die folgende Stellenausschreibung und extrahiere ALLE manuellen,
repetitiven oder zeitaufwändigen Aufgaben, die explizit oder implizit erwähnt werden.

Gib eine JSON-Liste mit kurzen deutschen Stichpunkten zurück.

Stelle:
{description}

Ausgabe (nur JSON):
{"pain_points": ["...", "...", "..."]}
```

### Step 2: Pitch Writer (uses Step 1 output)

```
# ROLLE
Du bist Yassir Chakour, Gründer von Shinobi Automation.
Du schreibst kurze, präzise B2B-Kaltakquise-E-Mails auf Deutsch.

# AUFGABE
Schreibe eine personalisierte Pitch-E-Mail an das Unternehmen, das die folgende
Stelle ausgeschrieben hat. Ziel: Automatisierung als Lösung anbieten.

# REGELN
- Schreibe ALS Yassir Chakour. Du bewirbst dich NICHT auf die Stelle.
- Keine Platzhalter wie [Name]. Wenn kein Name: "Sehr geehrte Damen und Herren,"
- Kein Tech-Jargon. Nutze: "Automatisierung", "Prozesse", "Abläufe". Niemals "n8n" oder "API".
- Maximal 90 Wörter. Kurz und prägnant.
- Exakt diesen Aufbau — kein anderes Format.

# AUFBAU
1. Anrede
2. "Ich habe gesehen, dass Sie Unterstützung für [Stelle] suchen."
3. Nenne 1-2 manuelle Aufgaben aus der Liste und zeige, dass sie Zeit fressen.
4. "Genau diese Abläufe automatisieren wir — [konkreter Nutzen]."
5. "Haben Sie die nächsten 5 Minuten für einen kurzen Austausch?"
6. "Beste Grüße,\nYassir Chakour\nShinobi Automation"

# BEISPIEL
Sehr geehrte Damen und Herren,

ich habe gesehen, dass Sie Unterstützung für Office Management suchen.
Kalender koordinieren, Reisen buchen, Belege erfassen — das kostet täglich
mehrere Stunden manueller Arbeit. Genau diese Abläufe automatisieren wir,
sodass Ihr Team sich auf das Wesentliche konzentrieren kann.

Haben Sie die nächsten 5 Minuten für einen kurzen Austausch?

Beste Grüße,
Yassir Chakour
Shinobi Automation

# EINGABE
Stelle: {job_title}
Unternehmen: {company_name}
Gehaltsrahmen: {salary_range}
Manuelle Aufgaben: {pain_points}
{optional: "# FEEDBACK VOM NUTZER\n{user_feedback}\nPasse die E-Mail entsprechend an."}

# AUSGABE
Nur der E-Mail-Text. Kein Betreff. Kein Markdown.
```

### Step 3: Output Validation (before sending to Telegram)
- Word count > 120 → log warning, try to regenerate once
- Contains `[` or `]` → placeholder leaked → regenerate
- Not German (langdetect check) → alert
- If 2nd generation also fails → send you the pitch with a ⚠️ warning tag

## 9. Log Rotation

Use Python's built-in `RotatingFileHandler` — zero manual work:

```python
from logging.handlers import RotatingFileHandler

handler = RotatingFileHandler(
    "logs/bot.log",
    maxBytes=1_000_000,   # 1 MB
    backupCount=3          # keeps bot.log.1, bot.log.2, bot.log.3
)
```

Automatically rotates. Old logs kept as `bot.log.1`, `bot.log.2`, `bot.log.3`. Fourth run overwrites the oldest.

```yaml

  scraper:
    build: .
    env_file: .env
    volumes:
      - ./data:/app/data             # persists applied_jobs.json
      - ./logs:/app/logs             # persists logs
      - ./screenshots:/app/screenshots
```

```bash
docker compose run --rm scraper
```

